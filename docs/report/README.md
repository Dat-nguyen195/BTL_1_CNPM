# Báo Cáo Dự Án (Project Reports)

Thư mục chứa toàn bộ các bài báo cáo tiến độ (Milestone / Submission Reports) của môn học Công nghệ Phần mềm (CO3001) - HK261.

## Cấu trúc thư mục:

```

│   ├── mau.png                 # Logo Trường ĐH Bách Khoa - ĐHQG-HCM (3508 x 2481)
│   └── README.md
├── scripts/                    # Scripts tự động hóa tạo / chèn nội dung báo cáo
│   ├── generate_md.py
│   └── insert_img.py
├── submission_1/               # Báo cáo Nộp Đợt 1 (Đặc tả Yêu cầu & Kịch bản Use Case)
│   ├── REPORT_SUBMISSION_1.tex
│   ├── REPORT_SUBMISSION_1.pdf
│   ├── REPORT_SUBMISSION_1.md
│   └── mau.png -> ../assets/mau.png

│   ├── mau.png -> ../assets/mau.png
```
